# Felege Genet Sema'etu Kidus Giorgis Church Website

Official website project for **Felege Genet Sema'etu Kidus Giorgis Church** (Ethiopian Orthodox Tewahedo Church, London, UK).

## Documentation

- **[SRS.md](file:///home/devnhm/Projects/Sara%20Church%20Project/SRS.md)**: Software Requirements Specification (Phase 1, v0.1 draft) prepared by Arch Solutions for trustee review.

## Project Summary (Phase 1)

Phase 1 delivers a clean, high-performance, mobile-first bilingual landing page to establish an official, trustworthy presence and help visitors find the church and attend services.

### Core Deliverables
- **Bilingual Landing Page**: English (`/`) and Amharic (`/am/`) with self-hosted Ethiopic typography (Noto Sans Ethiopic).
- **Find Us**: Text address, on-demand privacy-friendly interactive map (static image fallback), directions link (Google/Apple Maps), TfL public transport notes, and accessibility info.
- **Service Times & Notices**: Regular UK local times with short-notice alert banner capability.
- **Contact & Trust**: Tap-to-call/email, contact form with spam protection, UK charity disclosures (Charities Act 2011 s.39), privacy policy, and accessibility statement (WCAG 2.2 AA).
- **Content Maintenance**: Simple, secure mechanism for church volunteers to update service times and notices without developer involvement.

### Phasing
- **Phase 1 (Current)**: Landing page, location, contact, legal & accessibility statements.
- **Phase 2 (Post-Trustee Interviews)**: Mission & values, community support, full calendar (Gregorian & Ethiopian), clergy/leadership, policies.
- **Phase 3 (Future Candidates)**: Online giving (Gift Aid), sermon archive / livestreams, sacrament request forms.
